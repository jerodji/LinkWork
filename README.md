# LinkWork · 链接文案提取器

在浏览器右侧边栏粘贴一条链接，自动提取**视频口播稿 / 图文文案 / 网页正文**，一键复制。

架构：**浏览器插件（界面与取数）+ 本地 Python 服务（语音识别）**。

---

## 1.这是什么

一个**浏览器右侧边栏**里的小工具：把一条链接粘进去，点「提取文案」，它把里面的文字取出来给你复制。

| 你粘的链接                               | 你得到的内容                                     |
| ---------------------------------------- | ------------------------------------------------ |
| 抖音 / B站 / 小红书 / YouTube / 快手视频 | 视频里的**口播稿**（本地语音识别，不上传） |
| 小红书图文笔记                           | 笔记正文 + 图片里的文字（本地 OCR）              |
| 微信公众号 / 普通网页                    | 整理好的**正文**                           |
| 一段纯文字                               | 顺手整理排版                                     |

两种用法：

1. **自动模式（推荐）**：装一次「本机启动器」，以后**打开右侧面板就自动把服务启动起来**，不用开终端。
2. **手动模式**：每次开机后在终端跑一条命令常驻服务。适用于不想装本机启动器的人。

## 2.装之前先确认

| 项目   | 要求                                                                                           | 怎么确认                      |
| ------ | ---------------------------------------------------------------------------------------------- | ----------------------------- |
| 系统   | **macOS**（图片 OCR 和系统语音识别依赖 Apple 框架，Windows/Linux 用不了）                | 苹果菜单 → 关于本机          |
| 浏览器 | **Edge 或 Chrome**（114 以上版本）                                                       | 随便打开一个就行              |
| 终端   | 系统自带「终端」App                                                                            | `Command + 空格` 搜「终端」 |
| Python | **3.10 – 3.13** 且带 tkinter；**装了 `uv` 就免操心**（会自动下载合适的 Python） | 见下方                        |

不确定 Python 是否合适？直接装 `uv` 最省事（一条命令，它自带一个合适的 Python）：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

> 装 `uv` 后**新开一个终端窗口**，让 `uv` 进入 PATH。

还要准备：**项目文件夹**。如果你是从别人那里拿到的项目，把它放在一个路径里（比如 `~/Desktop/LinkWork`）。
**注意：项目放在哪个路径，插件的身份就由这个路径决定** —— 换了路径就要重新跑一次安装脚本（脚本会自动重新识别，不需要你手动改任何东西）。

## 3.安装（一条命令）

打开「终端」，进到项目文件夹，然后跑一条命令：

```bash
cd ~/Desktop/LinkWork          # ← 改成你自己的项目路径（把项目文件夹拖进终端即可自动补全）
./scripts/install_linkwork.sh
```

这条命令会依次自动完成：

1. 安装依赖（首次约 1–3 分钟，会自动建一个隔离的 Python 环境，不动你系统的 Python）
2. 编译并注册「本机启动器」，**自动识别你的浏览器和扩展 ID**（装了两个浏览器就两个都注册）
3. 打印接下来的两步，并帮你打开扩展管理页

看到 `✅ 安装流程结束` 就算好了。如果提示权限或找不到文件，看 [第 7 节](#用户7-出问题怎么办)。

## 4.装好后第一次用

### ① 在浏览器里加载插件（点两下）

安装脚本已经帮你打开了扩展管理页（没有的话手动打开）：

- Edge：地址栏输入 `edge://extensions/`
- Chrome：地址栏输入 `chrome://extensions/`

然后：

1. 打开右上角的 **开发人员模式**（Developer mode）
2. 点 **加载解压缩的扩展**（Load unpacked）
3. 在弹出的选择框里按 `Command + Shift + G`，粘贴这个路径后回车，再点「选择」：

   ```text
   ~/Desktop/LinkWork/extension
   ```

   （把 `~/Desktop/LinkWork` 换成你自己的项目路径）

装好后工具栏会出现 **LinkWork** 图标。

### ② 完全退出浏览器，再重新打开

`Command + Q` **完全退出**（不是关窗口）。注册信息只在浏览器启动时读取，所以这一步不能省。

### ③ 打开面板，确认连上了

点工具栏的 **LinkWork** 图标，右侧面板打开。右上角应该显示绿色圆点 + **连接已开启**，
「本地服务」那一栏会写「打开侧边栏时若服务没跑，会自动启动」。

第一次可能会看到「正在启动本地服务…」持续 1–2 秒，属正常。

## 5. 日常使用

1. 点工具栏 **LinkWork** 图标，打开右侧面板
2. 把链接粘到输入框（抖音/B站的分享链接、小红书笔记链接、公众号文章链接都行）
3. 点 **提取文案**（也可以按 `Command + Enter`）
4. 等进度跑完，点 **复制文案**

几个实用细节：

- **视频类**会自动在后台开一个不激活的标签页去取媒体地址，取完自己关掉
- **B站**优先用平台字幕，比语音识别更快更准
- 面板底部折叠区是**运行日志**，出错时展开看原因，点「复制日志」可以直接发给别人排查
- 「媒体缓存」那一栏显示下载过的媒体占了多少空间，可以一键清除，也可以勾「提取后自动清理」

**服务不用管**：面板打开时它会自己连（需要时自己启动），关掉面板只是断开连接，**不会中断正在跑的任务**。

## 6. 它在你的电脑上放了什么

| 位置                                                                                         | 内容                                                                     | 能不能删                   |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | -------------------------- |
| `<项目路径>/`                                                                              | 程序本体、`.venv`（Python 环境）                                       | 卸载时连这个文件夹一起删   |
| `~/Library/Application Support/Microsoft Edge/NativeMessagingHosts/com.linkwork.host.json` | 让浏览器允许面板启动本机服务的注册文件（Chrome 在`Google Chrome/` 下） | 卸载时删                   |
| `~/Library/Logs/LinkWork-service.log`                                                      | 服务运行日志（排查问题用）                                               | 可以删                     |
| `~/Library/Logs/LinkWork-native-host.log`                                                  | 本机启动器日志                                                           | 可以删                     |
| `~/Library/Caches/LinkWork/`                                                               | 下载的媒体与识别中间产物（会自动清理）                                   | 可以删，只是下次要重新下载 |
| `<项目路径>/output/`                                                                       | 命令行模式导出的结果                                                     | 可以删                     |

## 7. 出问题怎么办

### 面板显示「服务未连接」

按顺序检查：

1. **完全退出浏览器再打开**（`Command + Q`）—— 注册后没重启是最常见原因
2. 面板上点 **启动服务** 按钮，看日志区给出的原因
3. 看本机启动器日志：

   ```bash
   open ~/Library/Logs/LinkWork-native-host.log
   ```

### 面板提示「本机启动器未安装 / not found」

说明注册没成功或插件不是从注册时的目录加载的。重跑一次（会自动重新识别浏览器和扩展 ID）：

```bash
cd ~/Desktop/LinkWork
.venv/bin/python scripts/install_native_host.py
```

然后**完全退出浏览器再打开**。

### 提示「扩展 ID 不一致 / forbidden」

一般是项目换了路径，或插件是从别的目录加载的。在扩展管理页复制 LinkWork 卡片上的 **ID**，然后：

```bash
cd ~/Desktop/LinkWork
.venv/bin/python scripts/install_native_host.py --add-id 把刚复制的ID粘在这里
```

再完全退出浏览器重开。

### 提取时提示 `Operation not permitted: .../Caches/LinkWork/media/...`

说明服务被某个**受限环境**（沙箱、IDE 内置终端、某些 AI/自动化工具）启动了，那个环境不允许写缓存目录。
解决：用**普通终端**重新启动服务即可：

```bash
cd ~/Desktop/LinkWork
./scripts/service.sh stop
./scripts/service.sh start
```

（本机启动器启动的服务会先探测缓存目录是否可写，不可写会自动换一个可写目录并在面板日志里说明。）

### 安装脚本报「未找到可用的 Python」

装 `uv` 就行（见 [第 2 节](#用户2-装之前先确认)），它会自动下载合适的 Python：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 提取失败，提示需要登录 / 拿不到媒体地址

抖音、小红书等平台**未登录时不返回内容**。先在同一浏览器的对应网站登录，再从详情页复制链接重试。

### 还是不行

把这几个信息发给帮你部署的人，基本就能定位：

1. 面板底部「运行日志」→ 点「复制日志」
2. `~/Library/Logs/LinkWork-native-host.log` 的内容
3. 终端里跑 `cd <项目路径> && .venv/bin/python scripts/diagnose.py` 的输出

## 8. 卸载

```bash
# 1) 停掉可能还在运行的服务
cd ~/Desktop/LinkWork && ./scripts/service.sh stop

# 2) 删掉浏览器注册文件（Edge 用下面这条；Chrome 把 Microsoft Edge 换成 Google Chrome）
rm -f ~/Library/Application\ Support/Microsoft\ Edge/NativeMessagingHosts/com.linkwork.host.json

# 3) 在扩展管理页把 LinkWork 移除（点卡片上的「移除」）

# 4) 删掉项目文件夹与残留数据
rm -rf ~/Desktop/LinkWork ~/Library/Logs/LinkWork-*.log ~/Library/Caches/LinkWork
```

## 9. 隐私说明

- 本地服务只监听 `127.0.0.1:17890`（**只有这台电脑能访问**），且所有接口都要求一个网页无法伪造的自定义请求头
- 语音识别（faster-whisper / 系统语音）和图片 OCR（Apple Vision）**全部在本机完成**，音视频与图片不会上传到任何服务器
- 提取结果只显示在面板里、等你点复制；导出文件（命令行模式）保存在项目目录下的 `output/`
- 唯一的外部网络请求是：**访问你粘贴的那个链接本身**（以及它所在的平台资源）——和你自己打开那个网页是一样的

> **当前版本**：0.2.21　|　**许可**：[MIT](LICENSE)

| 层               | 负责                                 | 为什么这样分                                                                                                                                                                                     |
| ---------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

## 10.已知限制

- **抖音**：未登录时页面不返回文案，插件会明确提示需要登录。登录后由插件在页面里取数，才能拿到 `play_addr`。
- **小红书**：笔记页需要登录态；纯图片无文字的笔记只能拿到标题与话题。
- **视频号**：通常需要登录态。
- **媒体地址有时效**：必须在页面上打开视频后再提取，链接过期会报"媒体下载失败"。
- **自动启动服务需要先注册本机启动器**：没跑 `install_native_host.py`（或注册后没重启浏览器）时，
  面板会明确报「自动启动本地服务失败：Specified native messaging host not found」，
  此时用面板上的「启动服务」按钮同样无效，需先注册；排查日志见 `~/Library/Logs/LinkWork-native-host.log`。
- **macOS 上本机启动器必须是编译后的二进制**：浏览器执行 shell 脚本会被系统安全策略拦掉，
  表现是 `Native host has exited`（进程被拉起后立刻死掉，连日志都没有）。
  所以 `install_native_host.py` 会自动把 `native_host/linkwork-launcher.c` 编译成
  `native_host/linkwork-host` 并把它写进注册文件；没有 C 编译器时才退回 shell 包装脚本。
  注册后**必须完全退出并重开浏览器**才会生效。
- **提取时报 `Operation not permitted: .../Caches/LinkWork/media/...`**：说明服务是被某个
  **受限环境**（沙箱、IDE 内置终端、某些 AI/自动化工具）启动的，那个环境不允许写 `~/Library/Caches`。
  解决：`./scripts/service.sh stop` 后用普通终端重启，或让面板的「启动服务」按钮重新拉起
  （本机启动器会先探测缓存目录，不可写就自动换一个可写的并在面板日志里说明）。
- **扩展 ID 变了要重新注册**：把插件换个目录加载、或换了浏览器，ID 就变了，
  需要重跑 `install_native_host.py`（它会重新读取真实 ID）。
- 部分平台（36氪等）正文依赖前端渲染，网页抽取可能拿到导航文案。
